Systems Programming & Operating Systems

Virtual Memory Manager

C · GCC/Clang · Command-Line Tools · CSV

Project Overview

I developed a virtual memory manager in C that simulates how an operating system translates logical addresses into physical addresses.

The program uses a page table, a translation lookaside buffer (TLB), and demand paging to manage memory access. It supports multiple replacement algorithms, allowing me to compare their performance under different memory configurations and workloads.

My Contribution

I implemented the memory management simulation, including logical-to-physical address translation, page fault handling, TLB lookups, and page replacement.

I added configurable replacement policies, developed CSV logging for memory operations, and conducted experiments to examine how algorithms and memory access patterns affect performance.

Key Features

  • Address Translation: Translates 16-bit logical addresses into physical addresses.
  • TLB Management: Implements a 16-entry TLB with LRU and Random replacement.
  • Page Replacement: Supports FIFO, LRU, and Random algorithms.
  • Configurable Memory: Supports simulations using 128 or 256 physical frames.
  • Performance Tracking: Records page faults, TLB hits, and page replacements.
  • Workload Analysis: Compares random, sequential, looping, and stride-based memory access patterns.

Skills Demonstrated

C Programming · Systems Programming · Operating Systems · Algorithm Implementation · File I/O · Performance Analysis · Debugging

What I Learned

This project gave me a deeper understanding of virtual memory management and how operating systems balance memory efficiency with performance.

By comparing replacement policies and workloads, I learned how locality, memory access patterns, and available physical memory affect page fault rates and TLB performance.

Unix Command-Line Shell

C · Unix/Linux · POSIX APIs · Bash

Project Overview

I built a Unix-style command-line shell in C that allows users to execute commands through an interactive interface or batch input.

The project explores how operating systems create processes, execute programs, and coordinate command execution.

My Contribution

I implemented command parsing and execution using POSIX system calls. The shell supports multiple commands separated by semicolons and uses process creation and synchronization to execute external programs.

Key Features

  • Interactive Mode: Accepts and executes commands entered by users.
  • Batch Mode: Processes commands from an input file.
  • Multiple Commands: Supports semicolon-separated commands.
  • Process Creation: Uses fork() to create child processes.
  • Program Execution: Uses execvp() to execute external programs.
  • Process Synchronization: Uses waitpid() to manage child process completion.

Operating Systems & Algorithms

Multilevel Queue CPU Scheduler

C++ · Standard Template Library (STL) · Queues · Vectors

Project Overview

I developed a CPU scheduling simulator in C++ to model how different scheduling algorithms organize and execute processes.

The simulator calculates performance metrics to help compare scheduling behavior and understand how operating systems allocate CPU time.

My Contribution

I implemented four scheduling algorithms and used C++ data structures to manage processes and simulate CPU execution. I also implemented calculations for waiting time, turnaround time, and response time to evaluate scheduling performance.

Key Features

  • Priority Scheduling: Schedules processes based on priority.
  • Shortest Job First: Selects processes based on their execution time.
  • Round Robin: Allocates CPU time using time slices.
  • First Come, First Served: Executes processes in arrival order.
  • Process Tracking: Manages process information throughout the simulation.
  • Performance Metrics: Calculates waiting, turnaround, and response times.

Skills Demonstrated

C++ Programming · Algorithms · Data Structures · Operating Systems · Simulation · Problem-Solving

What I Learned

This project strengthened my understanding of CPU scheduling algorithms and the trade-offs involved in allocating processing time. It also helped me apply data structures and algorithmic thinking to simulate operating system behavior.
